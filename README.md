This repository contains an implementation for training a 124M parameter Large Language Model (LLM) from scratch on a dataset of 1 billion tokens. The training data follows a 30–70 split between general-domain and medical-domain text, enabling the model to learn both broad language understanding and domain-specific knowledge.

The project focuses on building and training the model architecture, handling large-scale data processing, and evaluating performance across both general and specialized tasks.
